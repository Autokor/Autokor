# AutoKor — موقع قطع غيار كيا وهيونداي (حلب)

## 1) النشر على GitHub Pages (مرة واحدة)
1. أنشئ مستودعاً جديداً على GitHub (Public).
2. اضغط Add file ← Upload files، واسحب **كل** محتويات هذا المجلد (مع مجلد assets)، ثم Commit.
3. Settings ← Pages ← Deploy from a branch ← main ← / (root) ← Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`
5. افتح `index.html` على GitHub (أيقونة القلم) واستبدل `USERNAME` و`REPO` في سطر `og:image` برابطك الحقيقي، ليظهر الشعار عند مشاركة الرابط.

## 2) إدارة القطع بدون كود (Google Sheets)
1. أنشئ جدولاً جديداً في Google Sheets، واستورد الملف `products-template.csv` (File ← Import ← Upload).
2. اكتب كل قطعة في سطر. الأعمدة: اسم القطعة، الشركة (Hyundai أو Kia)، الموديل، السنة، النوع، الحالة (جديد/مستعمل)، السعر (اتركه فارغاً ليظهر «عند الاستفسار»)، الصورة، ظاهر.
3. لإخفاء قطعة دون حذفها اكتب «لا» في عمود ظاهر.
4. File ← Share ← Publish to web ← اختر الورقة، والصيغة **CSV** ← Publish ← انسخ الرابط.
5. على GitHub افتح `config.js` وضع الرابط داخل `SHEET_CSV_URL` ثم Commit. هذه آخر مرة تعدّل فيها ملفاً.
6. بعدها أي تعديل في الجدول يظهر في الموقع خلال بضع دقائق.

## 3) إضافة صور القطع
- ارفع الصورة إلى المجلد `assets/products/` على GitHub (Add file ← Upload files)، واكتب **اسم الملف بالضبط** في عمود الصورة، مثل `filter-oil.jpg`.
- يفضّل صور مربعة أو 4:3 بحجم أقل من 200KB وأسماء إنجليزية بدون مسافات.
- القطعة بلا صورة تظهر بأيقونة افتراضية.

## ملاحظات
- رقم واتساب ورقم الاتصال يُضبطان من `config.js` فقط.
- لا تنشر سعراً أو توافقاً أو توفراً غير مؤكد.
- النماذج الستة في `products.js` تظهر فقط عندما يكون `SHEET_CSV_URL` فارغاً.
